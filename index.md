# Welcome to the Bracket Control Wiki

**Bracket Control** is a web platform for Discord communities to run esports tournaments. Create a one-off or recurring competition, register teams, review rosters, draft captains and free agents, report and confirm individual game victories, track match scores, publish brackets and share standings through Discord.

### Public tournament viewing

An organiser can share a direct tournament URL with you. It shows the event's **Bracket**, **Ladder** and **Match Results** as authorised. **Browse Tournaments** on the home page accepts shared public links; it is not a global list of every connected community.
