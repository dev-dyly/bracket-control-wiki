# Welcome to the Bracket Control Wiki

**Bracket Control** is a web platform for Discord communities to run esports tournaments. Create a one-off or recurring competition, register teams, review rosters, draft captains and free agents, report and confirm individual game victories, track match scores, publish brackets and share standings through Discord.

### Find what you need

- **[Getting started]({{ '/getting-started/' | relative_url }})** — signing in, choosing your Discord server and the app's main navigation.
- **[Complete user guide]({{ '/guides/user-guide/' | relative_url }})** — every main screen, role and tournament workflow.
- **[Organiser guide]({{ '/guides/organisers/' | relative_url }})** — series, divisions, readiness, publishing and administration.
- **[Captain guide]({{ '/guides/captains/' | relative_url }})** — registration, weekly confirmation, roster edits and match reporting.
- **[Draft tournaments]({{ '/guides/drafts/' | relative_url }})** — captain checkboxes, the 2/1/2/1 web draft and automated voice rooms.
- **[Troubleshooting]({{ '/troubleshooting/' | relative_url }})** — common login, evidence and Discord publishing problems.

### Public tournament viewing

An organiser can share a direct tournament URL with you. It shows the event's **Bracket**, **Ladder** and **Match Results** as authorised. **Browse Tournaments** on the home page accepts shared public links; it is not a global list of every connected community.
