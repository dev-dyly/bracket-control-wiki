# Report and confirm match results

For current tournaments, captains report each game they win. The opposing captain reviews the evidence before the game counts towards the match.

## 1. Report a game victory

1. Sign in with the Discord account assigned as your team's captain.
2. Open **Captain Dashboard**. Check the tournament, opponent and game number.
3. Under **One scoresheet (required)**, choose one screenshot or scoresheet showing that game's result.
4. Use PNG, JPEG, WebP or PDF, up to **10 MB**.
5. Select **Report Win** only if your team won that game.
6. Wait for the opposing captain to review it. Do not submit another game while a result is awaiting confirmation or disputed.

Existing captain links open the same team actions. Completed matches appear under **Match History**. Registration does not need to be open to report a live match.

## 2. Confirm or dispute

1. The opposing captain opens **Captain Dashboard** and finds the game awaiting confirmation.
2. Open the game's scoresheet link and check the reported winner.
3. If correct, select **Confirm Result**. No second screenshot is required to confirm.
4. If wrong, enter a **Dispute reason** and select **Dispute Result**.
5. After disputing, use **Optional dispute evidence** and **Upload supporting evidence** if you have relevant evidence.

A disputed game pauses the series until an organiser resolves it. Ask the organiser for help rather than submitting a competing victory report.

## 3. Understand game and match results

1. Each confirmed game increases the series score.
2. The first team to reach the required wins takes the match: one win for best-of-one, two for best-of-three, three for best-of-five.
3. When the match completes, Bracket Control updates the bracket and places the winner in its next match where appropriate.
4. Spectators use the tournament's **Match Results** page for confirmed match scores and game history.

## 4. Publish results in Discord

**Match Results** is an optional Discord destination. A community may call its channel **#claim-rank**. Claim Rank is a channel name, not a separate Bracket Control feature.

1. An organiser assigns the channel to **Match Results** during server setup, or checks the event's channel settings under **Manage Tournament → Settings**.
2. Confirmed game scoresheets and a match summary are published to that destination. The summary shows game winners, scoresheet links and the current or final series score.
3. Allow a short time for Discord delivery. A delay does not undo a result confirmed on the website.
4. For manual delivery options, open **Manage Tournament → Discord → Match results** and follow the available send action. Check **Discord delivery status** in the server's Discord settings if delivery fails.

The bracket image is configured separately under **Discord & publishing → Publish bracket**. **Final standings** becomes available after the tournament is complete; it is not the same as the Match Results destination.

Website evidence access is restricted to authorised accounts, but **confirmed scoresheets posted to Discord are visible to people who can access the results channel**. Upload only relevant match evidence and check channel access before publishing.

## 5. Organiser review and corrections

1. Open **Manage Tournament → Matches**.
2. Find the disputed game, read the reason and review the evidence.
3. Choose **Resolution**, review **Game winner**, enter **Administrator resolution reason** and select **Apply audited game resolution**.
4. If a confirmed game is wrong, select its **Correct Result — Game …** button. Set **Corrected game winner**, enter **Correction reason (required)** and select **Preview series and bracket impact**. Review the affected games and matches, complete any required approvals and select **Confirm reviewed correction** only after checking the proposed changes.
5. Tell affected captains if later matches must be replayed. Earlier evidence and correction history are retained.

If a tournament displays different reporting controls, follow the fields on that tournament or ask its organiser.
