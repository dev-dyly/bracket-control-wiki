# Create a tournament

**For:** Tournament administrators · **Reviewed:** 29 October 2026.

This procedure follows the supplied **Bracket Control Tournament Creation User Guide**, a 23-page illustrated walkthrough containing **30 recorded steps**. Its test-server values are examples, not recommended production defaults. The application source also confirms creation-only tournament rules and optional individual player acceptance.

## Step 1 — Start the wizard (PDF pp. 1–4; recorded steps 1–4)

1. Sign in to [Bracket Control](https://app.devdylnz.com/app/) and select the **correct Discord server**.
2. Open **Dashboard → + Create tournament**.
3. In **Basics**, enter a distinct **Tournament name**. Verify the server at the top of the page.

## Step 2 — Set tournament basics (PDF pp. 5–8; steps 5–9)

4. Select **Bracket format**: **Double elimination**, **Single elimination** or **Round robin**.
5. Set **Maximum approved teams** (supported capacity: **2–16**).
6. Select an existing **Division (optional)** when this tournament belongs to that division; otherwise leave it unassigned. Division membership and qualification are configured separately under [Divisions]({{ '/guides/divisions/' | relative_url }}).
7. Choose **Captain draft tournament** for a pop-up draft event, if applicable.
8. Decide whether to enable **Require Individual Player Acceptance**. If enabled, each listed starter, captain and substitute must complete their own applicable registration and tournament rules acceptance for competitive clearance. A captain cannot accept on their behalf.
9. Choose **Repeat this tournament weekly**, if appropriate. Review the options, then select **Continue**.

> **Permanent setting:** Tournament rules **and** the individual-acceptance policy are chosen at creation and cannot be edited, added or switched later. To change them, the authorised cancellation/replacement process is required; historical records and receipts are preserved. Availability of individual participation is subject to its release switch.

## Step 3 — Schedule and registration (PDF pp. 9–15; steps 10–18)

10. Verify **Tournament timezone** before any date/time entry, especially across daylight-saving changes.
11. Select the event day in **Every**, if it is a weekly tournament.
12. Set the **Start time**.
13. Set **Registration opens**. Check that it is before the tournament start.
14. Choose **Close registration (minutes before start)**.
15. For recurring events, choose **How teams return each week**: **New application every week** or **Prefilled roster; captain must check in**.
16. Review dates, timezone and repeat behaviour. Select **Continue**.

**Recurring reminder:** An unchanged approved roster can retain approval, but each occurrence still requires a captain's explicit attendance confirmation. Team registration, roster approval, attendance and personal rules acceptance are separate checks.

## Step 4 — Tournament rules (PDF pp. 16–17; steps 19–22)

17. Enter the event's **Tournament rules** and any game-specific modifiers; rules are mandatory for an event requiring individual acceptance.
18. Add a **Nonbinding supplementary HTTPS URL** only if appropriate. It does not replace the required tournament rules.
19. Expand **Preview tournament rules**, verify the final wording and select **Continue**.

## Step 5 — Discord delivery (PDF pp. 18–19; steps 23–24)

20. Review the effective Discord destinations. The system normally uses the division/server defaults unless you explicitly set series-specific overrides.
21. Expand **Choose custom Discord channels for this series (optional)** when required, confirm the destinations and select **Continue**.
22. **Creating a tournament does not, by itself, publish the bracket PNG, teams list or official announcement.** Review the event's Discord publishing controls and actual delivery status before sharing.

## Step 6 — Final review and creation (PDF pp. 20–23; steps 25–30)

23. Review the final summary, especially permanent rules and individual acceptance.
24. Tick **I confirm that tournament rules and individual acceptance are permanently locked after creation**.
25. Optionally open **Advanced match settings**. Review winners, losers, Grand Final and round-robin game formats; enable placement-tiebreak matches if required.
26. Verify the tournament name, division, capacity, dates and Discord channels one last time.
27. Select **Create tournament** **once**.
28. Return to **Dashboard**, locate the event, then use **Manage Tournament** to review the **Overview, Teams, Matches, Seed, Discord and Settings** tabs.

## After creation: get ready to play

Check that registration is open or scheduled, review [captain registrations]({{ '/guides/team-registration/' | relative_url }}), [approve teams]({{ '/guides/team-approvals/' | relative_url }}), resolve attendance and personal-acceptance requirements, then seed and generate a bracket only when readiness passes. Registration closing does not automatically generate a bracket.
