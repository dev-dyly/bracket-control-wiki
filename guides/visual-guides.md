# Illustrated user guides

These three guides accompany the screenshot-based PDF walkthroughs supplied for Bracket Control. Each link opens an up-to-date, readable online procedure covering the same task. Use the controls currently displayed in your own server.

## 1. Discord Server Setup

**[Open the Discord Server Setup guide →]({{ '/guides/server-setup/' | relative_url }})**

Based on the eight-page *Bracket Control Discord Server Setup Guide*. Covers selecting a server, choosing automatic or manual setup where offered, reviewing channels and roles, confirming resources, and safely resuming interrupted configuration.

## 2. Creating a Tournament

**[Open the Tournament Creation guide →]({{ '/guides/tournament-creation/' | relative_url }})**

Based on the 23-page *Bracket Control Tournament Creation User Guide*. Covers tournament basics, divisions, formats, registration schedules, permanent rules settings, Discord delivery, review and creation.

## 3. Team Captain Registration

**[Open the Team Captain Registration guide →]({{ '/guides/team-registration/' | relative_url }})**

Based on the eight-page *Bracket Control Team Registration User Guide*. Covers the Discord registration link, captain identity, team name, starters and substitutes, consent declaration and submission for administrator approval.
